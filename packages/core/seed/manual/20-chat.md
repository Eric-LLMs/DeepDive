# DeepDive 使用手册 · Chat 聊天基础

## 会话管理

- 会话列表在左侧 **Chats** 标签;点任意会话可恢复(Sessions 列表点击项)。新会话入口在 Chats 列表的 **New chat**。
- 发送:Enter 发送,Shift+Enter 换行。输入框左侧 **＋** 可附加本地文件/截图。
- 会话可重命名(rename)、删除(Delete,连同其导入到知识库的资产可选保留或移除)。

## 消息气泡操作

鼠标悬停在气泡上出现操作条:**Copy**(复制原文)、**Read**(🔊 语音朗读)、**Delete**(删除,可选同时删绑定的问答对)、**Edit**(仅限用户提问,编辑后可重新生成)、**Import to Knowledge**(把该问答对导入 RAG,成功后按钮变为 **✓ Imported**)。当本轮发生了检索,气泡下方还有 👍/👎 检索质量反馈。

## 输入栏工具(桌面端)

- **📎 附件**:引用云盘文件随消息发送。
- **📷 截图**:冻结当前窗口 → 拖拽框选区域(双击=整帧)→ 图片上传到云盘 `chat/temp/` 并挂为待发附件,气泡内显示缩略图。
- **🎤 语音输入**:按住说话(push-to-talk),转写进输入框,不自动发送。
- **🌊 免提通话模式**:再次点击挂断;朗读期间可随时插话。

## 打开文档/视频时的 Viewer 上下文(👁 FOCUS)

- 在 Files 里打开 PDF/电子书/视频后,Chat 顶部出现 **👁 聚焦徽章**(如 `文件名 · p.12` 或 `· 22:44`),表示当前页/当前字幕窗口会作为参考上下文自动注入提问。
- 回答中的 **[V1] [V2]** 角标可点击,跳回文档对应位置。
- 徽章上的 **✕** 仅断开视口注入(detach viewport),不影响其他附件。
- 选中文本可用 **📌 加入对话**;视频可用 **📌 Frame to Chat** 抓当前帧;图片/PDF 支持 ✂ 区域拾取。

## 过程展示

回答生成期间,聊天上方有一行动态状态(⋯ Working… / 💭 Thinking… / 🔍 Searching web… / 📚 Querying rag…),默认折叠为 💭 Thoughts 面板,点击可展开查看推理与工具调用过程;工具前的中间叙述也会折叠进该面板,正文只显示最终答案。
